# Repository instructions

- Do not create commits or push to any remote without explicit user approval for that action. Approval for an earlier checkpoint does not authorize committing or pushing subsequent changes.
- Keep camera capture on the single direct FFmpeg path. Preserve the single-thread RTSP decoder and newest-frame ownership policy.
- Treat CPU usage and bounded memory as requirements for camera previews and web streaming.
- Never print camera credentials, API keys, or private source URLs in diagnostics or test output.
